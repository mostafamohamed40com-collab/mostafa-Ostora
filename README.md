# رحلة مستكشف الفضاء 🚀
موقع تعليمي تفاعلي (HTML/CSS/JS) لتلاميذ الصف السادس الابتدائي — العلوم، الفصل الأول.

## التشغيل محليًا
افتح `index.html` في المتصفح مباشرة (لا يحتاج خادمًا ولا إنترنت عدا خط Cairo).

## الرفع على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع الملفات: `index.html` و`style.css` و`script.js` و`README.md`.
3. من Settings ← Pages ← Source: Deploy from a branch ← الفرع `main` والمجلد `/ (root)` ← Save.
4. بعد دقائق يظهر الرابط: `https://USERNAME.github.io/REPO/`

## تعديل المحتوى
الأسئلة والتفسيرات في `STAGES` والشرح في `LESSON` أعلى `script.js`، ودرجة النجاح في `PASS`.

## ملاحظة
التقدم والدرجات ولوحة الشرف محفوظة في LocalStorage لنفس المتصفح والجهاز فقط.
